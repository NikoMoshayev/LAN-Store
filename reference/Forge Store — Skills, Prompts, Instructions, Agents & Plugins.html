What's inside the Forge

Six artifact types, ready to drop into your workflow. Customize and scale your AI automation effortlessly.

MCP Server

An open standard for connecting the AI to external tools and services.

  • Exposes callable tools, such as file ops, databases & APIs
  • Can also provide resources and prompts
  • Configured in mcp.json, local or remote (http)
Example: The GitHub MCP server lets the agent work with issues, PRs & Actions.

Skill

An open standard for a reusable task or workflow.

  • Defined by a SKILL.md (name + when to use)
  • Loaded only when relevant, or run via / command
  • Bundles instructions with optional scripts & resources
Example: A create-PR skill that knows your team's PR format and opens it on GitHub.

Custom Agent

A persona for a specific role, such as planner, reviewer, or architect. Defined in an .agent.md file you switch to in chat.

  • Bundles its own instructions, tools & model
  • Restrict tools per role for safety (read-only planner)
  • Subagents & handoffs chain agents into workflows
Example: A read-only "Planner" agent that drafts a plan, then hands off to an "Implementer".

Prompt

A common task encoded as a reusable slash command, invoked manually in chat.

  • A .prompt.md file you run from the / menu
  • Simplifies common tasks: scaffolding, tests, or a PR
  • Can override a custom agent's default behavior
Example: A "prepare-PR" prompt that scaffolds the pull request the same way each time.

Instructions

Guidelines that the agent applies automatically to every request, so you don't repeat the same context each time.

  • copilot-instructions.md applies across the workspace
  • .instructions.md targets files via applyTo globs
  • Good for coding standards, conventions & tone
Example: Instructions that enforce naming conventions and "always write surgical changes".

Plugin

One installable package that bundles the other customizations together.

  • Can contain skills, instructions, prompts, agents & MCP servers
  • Installs a complete capability in a single step
  • Updates as one versioned package
Example: A "GitHub workflow" plugin bundling a PR skill, review instructions, and a GitHub MCP server.
