GBE NVM Builder Extension

✓ Download started

Installation Instructions

1
Wait for download

The gbe-nvm-builder-0.2.0.vsix file is downloading to your Downloads folder.

2
Open VS Code

Launch Visual Studio Code if it's not already running.

3
Install the extension
  • Press Ctrl+Shift+P
  • Type "Extensions: Install from VSIX"
  • Select the downloaded gbe-nvm-builder-0.2.0.vsix file
4
Reload VS Code

After installation completes, reload VS Code:

  • Press Ctrl+Shift+P
  • Type "Developer: Reload Window"
  • Press Enter
